# ListenWrite 使用说明

> 面向老师与学生的班级单词默写 + 班级史记应用使用指南。

## 一、快速开始

1. 打开班级主页（老师提供网址），选择你的班级
2. 输入班级口令进入（口令由老师公布）
3. 首次进入会看到引导弹窗，也可以在本页底部查看完整说明

![班级选择界面](docs/images/01-班级选择.png)

## 二、单词库

单词库用于管理班级所有单词，支持添加、编辑、批量导入、AI 智能补全。

### 添加单词
- 点击右下角 **＋** 按钮手动添加
- 或点击 **批量添加**，粘贴多行 `单词 释义` 快速导入
- 使用 **AI 补全** 自动生成释义

![单词库界面](docs/images/02-单词库.png)

### 发音功能
每张单词卡有两个发音按钮：

| 按钮 | 功能 |
|------|------|
| 🔊 标准发音 | 有道标准读音 |
| 🌐 全球发音 | 同学们录制的发音，点击可听，长按可录 |

![单词卡发音按钮](docs/images/03-发音按钮.png)

## 三、默写任务

1. 在单词库勾选要默写的单词
2. 点击 **创建任务**，设置日期与模式（听写 / 默写）
3. 学生完成任务后，老师可在历史记录中查看

![创建默写任务](docs/images/04-创建任务.png)

## 四、班级史记

班级史记是班级的图文日记，支持富文本编辑、插图、手写板。

### 插入图片
- 点击工具栏 **图片** 按钮选择相册图片
- 点击 **相机** 按钮直接拍照插入（手机/平板）
- 也可以直接粘贴截图（Ctrl+V）或拖拽图片到编辑器

![史记编辑器工具栏](docs/images/05-编辑器工具栏.png)

### 手写板
点击 **✏️ 手写板** 打开，可用鼠标 / 触摸 / 触控笔书写，完成后点击「插入编辑器」。

![手写板](docs/images/06-手写板.png)

## 五、班级图集

图集支持上传图片、GIF、MP4 视频，作为班级活动的照片墙。

- 点击 **选择文件** 上传，支持拖拽 / 粘贴
- 点击图片或视频可放大查看，视频支持点击播放
- 已看过的视频会缓存，再次打开秒开

![班级图集](docs/images/07-图集.png)

## 六、常见问题

**Q：单词太长，卡片上显示不全？**
A：长单词会自动滚动显示，点击卡片任意位置即可查看。

**Q：上传图片失败怎么办？**
A：检查图片大小（图片 ≤12MB、GIF ≤16MB、视频 ≤15MB）和格式（JPG/PNG/WebP/GIF/MP4）。失败原因会显示在上传框下方。

**Q：如何下载 APP？**
A：打开主页的「下载 APP」页面，或访问 GitHub Releases（CH-Hu-Bill）获取最新安装包。
