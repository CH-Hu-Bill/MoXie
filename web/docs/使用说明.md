# ListenWrite 使用说明

> 面向老师与学生的班级单词默写 + 班级史记应用使用指南。

## 一、快速开始

1. **在本机运行服务**：本应用运行在老师自己的电脑上，双击 `scripts\install.bat` 即可安装并后台启动（首次运行会自动放行防火墙）。
2. **同一局域网访问**：手机 / 平板 / 其它电脑需与这台电脑连接**同一个 WiFi（局域网）**，浏览器打开内网主网址（形如 `http://192.168.x.x:8000`）。
   - 忘记地址？在每个班级的「设置」页顶部、以及首页引导弹窗里都能看到**内网主网址**，可直接复制。
   - **外地 / 外网访问**：需要额外的「内网穿透」服务，请联系运行本服务的管理员。
3. 打开网址后选择你的班级，输入班级口令进入（口令由老师公布）。
4. 首次进入会看到引导弹窗，也可以随时在「设置」页底部重新查看。

![班级选择界面](docs/images/01-班级选择.png)

## 二、知识库

知识库管理班级的全部内容，分为 **单词 / 句子 / 作文** 三个板块（页面顶部标签切换，标签上的数字是数量角标）。

- **单词**：一行一个，支持发音、跟读、创建默写任务。
- **句子 / 作文**：一行一个（长内容可左右滚动查看 / 点击查看全文）；作文有标题。
- 支持添加、编辑、删除、批量导入、CSV 导入导出，以及 **AI 智能补全 / 直译**（需先在设置里配置 AI）。

![知识库界面](docs/images/02-单词库.png)

### 添加内容
- 点击右下角 **＋** 按钮手动添加（可切换单词 / 句子 / 作文）。
- 或点击 **批量添加**，粘贴多行内容快速导入；也可用 **AI 补全**自动生成释义。
- **作文可生成思维导图（实验性）**：若本班已在「设置」中配置 AI，添加作文时会多出一个「同时生成思维导图」选项。勾选后，系统会用 AI 生成一张**英文要点树**（≤3 层、≤20 个要点）用于记忆；此为**可选项**，不需要可不勾。

### 发音与跟读
每张单词卡有两个发音按钮：

| 按钮 | 功能 |
|------|------|
| 🔊 标准发音 | 有道标准读音 |
| 🌐 全球发音 | 同学们录制的发音，点击可听，长按可录 |

「跟读」仅针对**单词**（按顺序或随机朗读，可调次数与缓冲）。

![单词卡发音按钮](docs/images/03-发音按钮.png)

## 三、默写任务

1. 在知识库勾选要默写的内容（单词 ≤20，句子 / 作文不限）。
2. 点击 **创建任务**，设置日期与模式。
3. 学生完成任务后，老师可在历史记录中查看。

默写支持三种模式：**看词**（show）、**默写**（hide，隐藏英文看中文）、**听写**（dict，仅单词）。默写页会把任务中的单词 / 句子 / 作文混合展示。

### 作文按思维导图默写（可选）
- 若作文已生成思维导图，默写作文时**默认展示思维导图**：学生看英文要点、写出英文全文。
- 可在「设置 → 作文默写方式」改为**按中文默写**（展示中文释义）。
- **没有思维导图的作文会自动回退到中文默写**。
- 作文详情页（在作文库点开某篇）也会展示该作文的思维导图。
- 说明：仅对**导入时勾选生成**的新作文生效，以前的作文不受影响，也不支持事后补生成。
- **编辑作文时**：若该作文已有思维导图且改动了英文 / 标题，保存后会**自动重新生成**思维导图（需 AI 可用）；若 AI 不可用，会提示「导图未能更新」，作文内容照常保存、导图保留为之前的版本。

![创建默写任务](docs/images/04-创建任务.png)

## 四、班级史记

班级史记是班级的图文日记，支持富文本编辑、插图、手写板。

### 插入图片
- 点击工具栏 **图片** 按钮选择相册图片
- 点击 **相机** 按钮直接拍照插入（手机 / 平板）
- 也可以直接粘贴截图（Ctrl+V）或拖拽图片到编辑器

![史记编辑器工具栏](docs/images/05-编辑器工具栏.png)

### 手写板
点击 **✏️ 手写板** 打开，可用鼠标 / 触摸 / 触控笔书写，完成后点击「插入编辑器」。

![手写板](docs/images/06-手写板.png)

## 五、班级图集

图集支持上传图片、GIF、MP4 视频，作为班级活动的照片墙。

- 点击 **选择文件** 上传，支持拖拽 / 粘贴
- 点击图片或视频可放大查看，视频支持点击播放
- MP4 自动生成首帧缩略图，视频进视口才播放，节省流量

![班级图集](docs/images/07-图集.png)

## 六、展示大屏

「设置 → 展示大屏」可生成一条**带 token 的免口令链接**，用于把页面设为电脑壁纸（如 Lively Wallpaper）或在希沃等大屏上滚动展示：顶部公告跑马灯 + 今日默写单词 + 班级图集轮播，只读展示、不涉及任何修改。

## 七、班级设置

在班级「设置」页可以：

- **内网主网址**（页面顶部）：显示当前服务的局域网地址，一键复制。
- **英文字体（仅影响英文）**：把英文从「默认手写字体」切换为更易辨认的教学字体 **Andika**；中文始终使用手写字体。切换后点页底「保存设置」生效，本班全局生效。
- **听写 / 朗读 / 跟读参数**、**图集公开 API 密钥**、**展示大屏 token**。
- **AI 设置**：配置本班级的 AI 接口（OpenAI 兼容 / Anthropic），用于智能补全、翻译等；Web 与 APP 共用，未配置则相关功能提示不可用。

## 八、常见问题

**Q：单词太长，卡片上显示不全？**
A：长内容会自动来回滚动显示，点击卡片即可查看详情。

**Q：打开网页提示"拒绝连接"？**
A：通常是 PHP 缺少运行库（Windows 需 VC++ 2015–2022 x64 运行库）。执行 `runtime\php\php.exe -v` 查看报错，安装运行库后重新运行 `scripts\install.bat`。

**Q：其它设备打不开？**
A：确认手机与电脑在**同一 WiFi**，并使用**内网主网址**（不是 `127.0.0.1` / `localhost`）。

**Q：上传图片失败怎么办？**
A：检查图片大小（图片 ≤12MB、GIF ≤16MB、视频 ≤15MB）和格式（JPG/PNG/WebP/GIF/MP4）。失败原因会显示在上传框下方。

**Q：如何下载 APP？**
A：打开主页的「下载 APP」页面，或访问 GitHub Releases（CH-Hu-Bill）获取最新安装包；下载页也提供历史版本。
