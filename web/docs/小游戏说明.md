# 小游戏说明

当前班级内置 5 个小游戏：

- **2048**
- **别踩白块**
- **拳皇**
- **人生重开模拟器**
- **数独工坊**

游戏时长按班级统一计算，每天 0 点重置；管理员可在后台「小游戏时长」设置上限，留空或填 `0` 表示不限时。到上限后游戏页会提示时间用完。游戏列表顶部会显示**近 7 天游玩时长曲线**，含今天。

---

## 2048

### 目标

把相同数字的方块合并，最终得到 **2048**。

### 操作

- 电脑：方向键 / WASD
- 手机 / 平板：在棋盘上滑动
- 每次滑动，所有方块朝该方向移动；两个相同数字相撞会合并成一个，数字翻倍。

### 简单策略

1. 先固定一个角落，尽量把大数字放在角落。
2. 尽量不要让大数字离开角落。
3. 优先保持一行/一列整齐，不要到处乱塞。
4. 棋盘快满时，优先合并小数字腾空间。

## 别踩白块

### 目标

只点**黑块**，不要踩到白块。点得越快，分数越高。踩错或漏掉黑块会结束。

### 模式

- **经典**：固定速度，按顺序点黑块。
- **街机**：黑块不断下落，速度越来越快。
- **禅**：限时内尽量多点，适合放松。
- **极速**：速度提升更快，挑战反应。
- **接力**：连续完成多轮。
- **设置**：调整音效等选项。

### 操作

- 手机 / 平板：直接点击或按住黑块。
- 电脑：鼠标点击黑块。

### 小提示

1. 先看清下一块的位置，再出手。
2. 不要连续乱点；点错白块会直接失误。
3. 分数会保存在本机浏览器里，换设备不会同步。

## 拳皇（双人同屏）

### 目标

两位同学在同一块屏幕上一对一对战，先把对方血量打到 0，或在 60 秒倒计时结束时血量更高的一方获胜。

### 屏幕按键

游戏画面**下方**左右各有一组实体风格按键，不遮挡游戏画面：

| 位置 | 同学 | 移动 | 跳跃 | 攻击 |
|---|---|---|---|---|
| 左侧 | P1 | ← / → | 跳 | 拳 |
| 右侧 | P2 | ← / → | 跳 | 拳 |

- 手机 / 平板：两位同学分别站在设备左右两边，用拇指按自己一侧的按键。
- 电脑键盘：P1 用 `A` / `D` 移动、`W` 跳跃、`空格` 攻击；P2 用 `←` / `→` 移动、`↑` 跳跃、`Enter` 攻击。
- 中间「重开」可以重新开始一局。
- 手机建议横屏；横屏时人物和血条更清楚。

### 小提示

1. 攻击距离有限，靠近对方再出拳。
2. 跳起后可以移动，用来躲避攻击。
3. 不要一直按拳；挥空后有短暂硬直。

## 人生重开模拟器

### 流程

1. 点「立即重开」开始。
2. 点「10 连抽！」抽取天赋，从 10 个里选择 **3 个**。
3. 分配初始属性点：颜值、智力、体质、家境，每项 0–10；天赋可能会额外增加点数。
4. 点「开始新人生」，然后点击人生轨迹区域（电脑也可以按空格或回车）推进年龄。
5. 生命结束后查看人生总结，可以选一个本局天赋带到下一世。

### 界面说明

- 顶部显示当前年龄和五维属性：颜值、智力、体质、家境、快乐。
- 中间是逐年发生的人生事件；点一下推进一年。
- 右上角「黑 / 白」可以切换深色、浅色主题。
- 「人生总结」在生命结束后出现。
- 右上角的重开按钮可以重新开始一局。

### 小提示

1. 天赋组合比单项属性更重要，优先选能互相配合的天赋。
2. 属性点可以只加几项，不一定要平均分配。
3. 人生事件有随机性，同一套天赋也可能走出不同结局。
4. 本游戏为经典版人生重开模拟器，内容偏段子和随机事件，适合课间轻松玩。
5. 手机/平板横屏时会自动切换紧凑布局，抽选天赋和调整属性不会被裁切；竖屏仍保持原版布局。

## 数独工坊

### 目标

在 9×9 盘面中填数字：

> **每行、每列、每个 3×3 宫都要包含 1–9，且不能重复。**

### 操作

1. 点击一个空格。
2. 按数字键 `1–9`，或点屏幕上的数字。
3. 填错的数字会高亮。
4. 卡住时可以：
   - 开启「候选笔记」，记录这个格子可能的数字；
   - 使用「提示」，会解释一步推理；
   - 使用「撤回」回到上一步。
5. 一题完成后进入下一题。

### 新手方法

1. **先找唯一数**：某一行/列/宫已经出现了 8 个数字，剩下那个就是答案。
2. **再看候选**：一个格子只剩一个可能数字时，直接填。
3. **不要猜**：先做能确定的，猜错会越来越乱。
4. 数字多的时候，先处理数字 1、2、3 或已经出现很多的数字。

### 难度说明

数独本身是逻辑游戏，不要求速度。慢慢推、用候选笔记，比快速乱填更容易完成。开局会先显示玩法说明，点「我知道了，开始」后才开始计游戏时长。
