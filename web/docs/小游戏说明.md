# 小游戏说明

当前班级内置两个小游戏：

- **2048**
- **数独工坊**

游戏时长按班级统一计算，每天 0 点重置；管理员可在后台「小游戏时长」设置上限，留空或填 `0` 表示不限时。到上限后游戏页会提示时间用完。

---

## 2048

### 目标

把相同数字的方块合并，最终得到 **2048**。

### 操作

- 电脑：方向键 / WASD
- 手机 / 平板：在棋盘上滑动
- 每次滑动，所有方块朝该方向移动；两个相同数字相撞会合并成一个，数字翻倍。

### 简单策略

1. 先固定一个角落，尽量把大数字放在角落。
2. 尽量不要让大数字离开角落。
3. 优先保持一行/一列整齐，不要到处乱塞。
4. 棋盘快满时，优先合并小数字腾空间。

## 数独工坊

### 目标

在 9×9 盘面中填数字：

> **每行、每列、每个 3×3 宫都要包含 1–9，且不能重复。**

### 操作

1. 点击一个空格。
2. 按数字键 `1–9`，或点屏幕上的数字。
3. 填错的数字会高亮。
4. 卡住时可以：
   - 开启「候选笔记」，记录这个格子可能的数字；
   - 使用「提示」，会解释一步推理；
   - 使用「撤回」回到上一步。
5. 一题完成后进入下一题。

### 新手方法

1. **先找唯一数**：某一行/列/宫已经出现了 8 个数字，剩下那个就是答案。
2. **再看候选**：一个格子只剩一个可能数字时，直接填。
3. **不要猜**：先做能确定的，猜错会越来越乱。
4. 数字多的时候，先处理数字 1、2、3 或已经出现很多的数字。

### 难度说明

数独本身是逻辑游戏，不要求速度。慢慢推、用候选笔记，比快速乱填更容易完成。
