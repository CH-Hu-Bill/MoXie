# 人生模拟器 · Life Simulator

一个纯前端实现的网页版人生重开模拟器：随机天赋、自由加点，从呱呱坠地到生命终点，体验千百种截然不同的人生。

## 在线游玩

部署于 Vercel（见仓库 About / 部署记录）。

## 玩法

1. **天赋抽取**：每局随机 10 个天赋（普通 / 稀有 / 史诗 / 传说），最多选 3 个。
2. **属性分配**：20 点自由分配到颜值 / 智力 / 体质 / 家境，剩余点数转化为快乐。
3. **人生推演**：一年一年推进，经历求学、中考高考、求职晋升、恋爱结婚、生儿育女、退休养老……关键节点需要做出选择。
4. **隐藏路线**：传说天赋「天命之人」可开启修仙线，炼气 → 筑基 → 金丹 → 元婴 → 化神 → 渡劫飞升。
5. **结局评分**：生命结束后按寿命、属性、财富、成就综合评分，解锁 30 个成就（本地存档）。

## 内容规模

- 天赋 51 个、事件 125 个、成就 30 个
- 职业 14 种，支持晋升 / 跳槽 / 裁员 / 创业 / 上市
- 完整学业线（小学 → 中考 → 高考 → 大学 → 考研 / 考公 / 创业）

## 技术

- 原生 HTML / CSS / JavaScript，零依赖、零构建，任意静态托管即可部署
- 逻辑与视图分离：`js/engine.js` 为纯逻辑引擎（可在 Node 中直接跑自动化模拟测试）
- 数据驱动：天赋 / 事件 / 成就均为声明式数据文件，易于扩充内容

## 目录结构

```
index.html            页面骨架
css/style.css         样式
js/data/talents.js    天赋数据
js/data/achievements.js 成就数据
js/data/events/*.js   分阶段事件库（童年/校园/职场/老年/特殊）
js/engine.js          核心推演引擎
js/ui.js              界面交互
```
